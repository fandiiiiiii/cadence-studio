## 三、15 条标注规则

### 1. 结构标签有哪些

- 规则 ID：`functions`
- 所属组：结构总则
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnMRFoqFJZIyAWgIkEfeyECf)

1. 常见音乐段落：Intro、Verse、Pre-chorus、Chorus、Interlude、Bridge、Outro。
2. 电子音乐常见段落：Breakdown、Build-up、Drop。不同项目可能对结构名称有不同定义。
3. 非音乐声音可标 Silence、Spoken、Applause、Noise 或其他对应英文名称；短结构包括 Fill、Break、Hold；Section 以 A、B、C、D 等字母表示。

### 2. 结构名称 + 字母 + 编号

- 规则 ID：`section-naming`
- 所属组：结构总则
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnl4vVcBCdKJsn5LpdDIL3Hd)

1. 格式为结构名称 + 乐章字母 + -n。Pattern 相同使用相同字母；旋律动机改变时，字母依次往下。
2. 同一字母大段中的重复小段依次标 -1、-2、-3；二级结构至少为 2 小节。大部分旋律动机相同，可作为重复小段，例如 A-1、A-2。
3. 弱起结构使用 0，例如 A-0。

### 3. 小段如何划分

- 规则 ID：`section-length`
- 所属组：结构总则
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnl4vVcBCdKJsn5LpdDIL3Hd)

1. 中慢速通常按 4 小节划分；特别慢时可能为 2 小节；快速时可综合旋律线条完整性，放宽到 8–16 小节。
2. 划分时要保持旋律完整连贯，不要为了细分而过度切割。即兴、Freestyle、Cadenza 可放宽结构标注精细度。

### 4. 开头、结尾与非音乐声音

- 规则 ID：`beginning-end`
- 所属组：结构总则
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnl4vVcBCdKJsn5LpdDIL3Hd)

1. 从 0.000 秒到出现声音之前标 Silence；纯说话声标 Spoken，纯鼓掌声标 Applause，纯噪音标 Noise，其他声音可手动填写相应英文名称。
2. 音频文件结尾标 End，表示结束。

### 5. 时间点精度

- 规则 ID：`time-precision`
- 所属组：结构总则
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnl4vVcBCdKJsn5LpdDIL3Hd)

1. 结构开始时间尽量精确：拍点、律动明确时误差小于 15 ms；拍点不明确或模糊时误差小于 50 ms。

### 6. 不要把所有曲风硬套成 Verse / Chorus

- 规则 ID：`structure-flex`
- 所属组：结构总则
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnl4vVcBCdKJsn5LpdDIL3Hd)

1. 非 Pop 或融合电子的歌曲可按听感使用特殊结构名。段落整体能量与前段相比突然降低并明显抽离，可考虑 Breakdown；鼓点与节奏逐渐密集、Riser 音效逐渐上升，可考虑 Build-up。
2. 部分歌曲尤其是纯音乐确实没有对应结构名称时，Function 可以留空，不必强行指定。

### 7. Fill · 填充 / 过渡

- 规则 ID：`fill`
- 所属组：短结构
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/JFLYdrpvGoU8buxMBZ6cfyEQnGh#PfoadsVJJonWIYxZi9Ec82ADnJg)

1. 乐器演奏中的加花或过渡，用来连接段落，通常与主旋律无关；鼓 Fill、其他乐器 Fill，以及吉他或 Bass 的 Slide 均可能符合。
2. 重点检查段落之间；段尾出现律动变化需要标 Fill。原文要求鼓的 Fill 必标，即使正拍前只有一个 Crash 也要标。
3. FX、Riser 和滚镲不算 Fill。段内或最后一个 Break 之前，如果 Fill 明显，也需要标记。
4. 短结构从特征开始的位置标记，Section 字母和数字跟随与它强关联的 Function 段落。多件乐器一起 Fill 时，选择一个主旋律乐器作主奏，其余作伴奏，时间点取最早出现 Fill 的乐器。

**原文示例：**

- [队长《11》：原文标记 35s](https://music.163.com/song?id=1907766514&userid=269529647)
- [Guns N’ Roses《Don’t Cry》：原文标记 17s](https://music.163.com/song?id=28952211&userid=269529647)
- [丁世光《爱我的人》：原文标记 2.20s](https://music.163.com/song?id=2659586240&userid=269529647)

### 8. Break · 切口

- 规则 ID：`break`
- 所属组：短结构
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/JFLYdrpvGoU8buxMBZ6cfyEQnGh#G8j8dj5V9oh2QLxcZ7Bcx9IhnIh)

1. 短暂的停顿或空白，整体能量突然抽离，常用于强调下一部分，也常与 Fill 一起出现。
2. 需要有明显的整体能量抽离；只去掉 Kick 不一定算 Break。磁带骤停可以算 Break，标在骤停开始位置。
3. 如果 Break 本身持续作为 Groove 的一部分反复出现，不必每次都打；标记段落之间明显的 Break 和较独特的 Break。Fill 同理。
4. 段内 Break 结束后要重新标记当前段落；若结束后直接进入下一段，就直接标下一段。

- [丁世光《爱我的人》：原文标记 2.19s、3.17s](https://music.163.com/song?id=2659586240&userid=269529647)

### 9. Hold · 延长

### 10. 短结构的先后与衔接

- 规则 ID：`short-timing`
- 所属组：短结构
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnl4vVcBCdKJsn5LpdDIL3Hd)

1. 建议先标完整体结构，再标短结构。短结构与常规结构的标注格式一致。
2. 连续出现两个短结构时，以下一个常规结构的开始时间作为两个短结构的结束时间。
3. 原文规定：短结构的 Section 与下一个常规结构相同时，下一个常规结构的实际开始时间为该短结构的开始时间。
4. 开头正拍之前的 Pad / FX 类元素标为弱起；持续较长时考虑单独划出 Intro。

### 11. 结构标注项目的抛弃条件

- 规则 ID：`discard`
- 所属组：抛弃规则
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#N9J6dmsDKotys7xRu0Wcn2TpnBl)

1. 不满足轻量化筛选标准，即音质与音乐性未同时达到 Yes 的音频需要抛弃。
2. 不足 30 秒的音频、伴奏需要抛弃。
3. Loop / 罐头音乐、DJ、拼接音频、下沉音乐需要抛弃并备注。
4. 这些条件来自结构、调性、配器与节拍标注项目，应结合当前项目口径使用。

### 12. 每个段落如何标调性和配器

- 规则 ID：`key-instruments`
- 所属组：调性与配器
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnym5pR6uSOmN56RNRMGFhQb)

1. 每个段落标一个 Key 和一个 Mode（调性）。
2. 每个段落标一个主奏乐器与多个伴奏乐器。需要听辨时可打开「音色试听」查看原文示例。

### 13. 节拍：按整首主要节拍标注

- 规则 ID：`meter`
- 所属组：节拍与速度
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnWcmBy5IuWPVxXp5lapuurd)

1. 按每首音乐的主要节拍标注。如果中间发生变拍，在 Remark 栏备注「有变拍」。

### 14. 速度：以每分钟四分音符数计

- 规则 ID：`tempo`
- 所属组：节拍与速度
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnwzcsJZxHtEteJsyZe0pjGc)

1. 标注四分音符在一分钟内出现的次数，不论乐曲以四分音符还是八分音符为一拍。
2. 段落内变速时，按时间占比最大的速度标注并备注；速度不稳定但主观上意图恒速演奏时，标注大致均值并备注。
3. 渐快、渐慢或自由节拍的段落选择相应标签，无需填写具体 Tempo 数字。

### 15. 标注操作顺序

- 规则 ID：`workflow`
- 所属组：平台操作
- [原始规则来源](https://wavesoundlab.feishu.cn/docx/Ow2JdftcuoDCFQx1HZqcise4nmg#doxcnrecxFGL16c4Sw5vo6CliEh)

1. 第一步：调整到编辑模式，在需要标注的位置点击，完成结构段落打标。
2. 第二步：打开标签编辑栏，添加结构、调性与配器标签。
3. 第三步：标注节拍。原文还提供了对应界面截图，可通过原文链接查看。
